# 만화 뷰어 (SM-T530 / Android 4.1+)

PDF 만화 뷰어. 양면 보기, 우→좌(일본식) 정렬, 표지 단독 페이지 지원.

## 빌드
1. 이 폴더 전체를 GitHub 저장소에 push
2. Actions 탭 → "Build APK" 실행 결과 → Artifacts의 `ComicViewer-debug-apk` 다운로드
3. 태블릿에 APK 설치 (설정 > 보안 > 출처를 알 수 없는 앱 허용)

## 조작
- 화면 가운데 탭: 메뉴 표시/숨김
- 화면 좌/우 가장자리 탭 또는 스와이프: 페이지 넘김 (일본식에서는 왼쪽 탭 = 다음)
- 더블탭 / 핀치: 확대, 확대 중 드래그: 이동
- 볼륨 하단 = 다음, 볼륨 상단 = 이전
